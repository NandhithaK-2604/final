Redesign the Transaction Approval workflow to make the Actions column cleaner and more professional.

The Actions column should contain only:
[ Review ]
The Review button is the primary action because this is an Approval page.
When the user clicks Review, open the existing Transaction Review/Review & Approve page.
On the Review page, add a small secondary button near the transaction/payee information:
View Payee Details
This button should allow the user to view the complete payee details for the transaction.
When clicked, display the payee information in a clean side panel or modal without leaving the Review page.
The Review page should contain:
Batch ID
Maker
Debit Account
Amount
Transaction Currency
Payment Date
Status
Transaction/payee information
View Payee Details secondary button
Reject and Approve actions
Important UX requirements:
Review is the primary action.
View Payee Details is a secondary action.
Do not use a three-dot dropdown on the main table.
Do not make the user search through menus to find payee details.
Do not approve anything when Review is clicked.
The user should review all information first and then explicitly click Approve or Reject.
