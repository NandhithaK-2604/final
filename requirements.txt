10. MAIN CONTENT POSITIONING
============================================================

This is one of the most important changes.

Currently, some pages appear to have too much empty space between the Sidebar and the content.

Fix the common layout so the distance is consistent.

The relationship should be:

SIDEBAR
   ↓
small/controlled gap
   ↓
MAIN CONTENT

Target approximately:
- 24–32px horizontal gap/padding

Do NOT use random page-specific margin-left values.

Do NOT give every page a different content offset.

The common layout should control the main content positioning.

Use an appropriate flex/grid structure.

The main content should use the remaining available width.

Prefer a layout concept such as:

display: flex;

Sidebar:
fixed width

Main content:
flex: 1;
min-width: 0;

Avoid unnecessary:
width: 100vw;

if it causes horizontal overflow.
