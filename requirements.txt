> Prompt:

Add a Light Mode / Dark Mode theme toggle to my existing SavnyaPay Transaction Management website.

Important: Do NOT change the existing layout, sidebar, navigation, table structure, spacing, typography, icons, buttons, filters, or functionality. Keep the current UI exactly as it is and only introduce theme support.

Place a small theme toggle icon in the top-right header, positioned between the notification (bell) icon and the user/profile icon.

In Light Mode, show a moon icon 🌙 to indicate that clicking it will switch to Dark Mode.

In Dark Mode, show a sun icon ☀️ to indicate that clicking it will switch back to Light Mode.

Use a clean, professional outlined icon style, matching the existing header icons.

Do not use a large toggle switch; use a compact icon button.

Add a subtle hover effect and tooltip such as "Switch to dark mode" / "Switch to light mode".
