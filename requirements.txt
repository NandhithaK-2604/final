I want you to professionally improve the UI of User Story 2 / Payroll pages.

The goal is to make the UI look clean, modern, polished, professional, and consistent with a corporate banking application like Standard Chartered Straight2Bank.

IMPORTANT:
Do not change the existing functionality, business logic, API calls, routing, validation, state management, or behavior. This task is primarily for UI/UX improvement.

DESIGN REQUIREMENTS:

1. FONT & TYPOGRAPHY
- Use the existing application font if one is already configured.
- If there is no suitable font, use a clean professional sans-serif font.
- Establish a consistent typography hierarchy:
  - Page titles: approximately 24px, semibold
  - Section headings: 18–20px, semibold
  - Body/table text: 14px
  - Labels: 13–14px, medium/semibold
  - Secondary/helper text: 13–14px
- Avoid overly large, bold, or decorative text.
- Make all text easy to read and visually balanced.

2. COLORS
- Follow a professional corporate banking color palette.
- Use Standard Chartered-inspired blue as the primary/accent color.
- Keep the overall UI mostly white/light neutral backgrounds.
- Use dark navy/dark gray for important text.
- Use muted gray for secondary text.
- Use subtle colors for borders and backgrounds.
- Avoid excessive bright colors, gradients, or unnecessary visual effects.

3. SPACING & ALIGNMENT
- Make spacing consistent throughout all User Story 2 pages.
- Use a consistent content padding and gap between the sidebar and main content.
- Align page titles, buttons, cards, tables, forms, and other elements properly.
- Use consistent margins and padding instead of page-specific random values.
- Avoid excessive empty space.
- Make the UI feel balanced and not cramped.

4. CARDS & CONTAINERS
- Use clean white cards with subtle borders.
- Use small, professional border-radius values.
- Use very subtle shadows only where necessary.
- Keep card padding consistent, approximately 20–24px.
- Avoid overly large cards or unnecessary decoration.

5. TABLES
- Make tables clean and professional.
- Use a consistent blue table header with readable white text.
- Use approximately 14px table text.
- Give cells appropriate padding.
- Align numbers, dates, statuses, and actions properly.
- Use subtle row borders/dividers.
- Make sure the table fits naturally within the content area.
- If horizontal scrolling is required, apply it ONLY to the table container, not the entire page.
- Prevent unnecessary page-level horizontal scrolling.

6. BUTTONS
- Make buttons consistent throughout User Story 2.
- Use approximately 40px height.
- Use appropriate horizontal padding.
- Use a professional 6px–8px border radius.
- Primary actions should use the primary blue.
- Secondary actions should use clean outlined styling.
- Destructive actions such as Delete should be visually distinguishable but not overly aggressive.
- Keep button text around 14px and medium/semibold.

7. STATUS BADGES
- Make Draft, Pending, Approved, Rejected, etc. look like clean professional status badges.
- Use subtle background colors with readable text.
- Keep the badge size and padding consistent.

8. FORMS & MODALS
- Make labels, inputs, dropdowns, and date fields consistent.
- Inputs should have comfortable padding and a consistent height.
- Use subtle borders and clear focus states.
- Improve spacing between form fields.
- Make modal titles, content, and action buttons properly aligned.
- The Create Payroll Batch modal should look clean and professional.

9. PAYROLL DETAIL PAGE
- Improve the hierarchy of Batch ID, Debit Account, Currency, and Payment Date.
- Keep metadata aligned and easy to scan.
- Organize Add Payee, Reset Rows, pagination, and bottom action buttons neatly.
- Make the page look like a professional banking workflow rather than a basic CRUD page.

10. RESPONSIVENESS
- The layout should work properly at different screen sizes.
- Do not allow the sidebar and main content to overlap.
- Do not introduce unnecessary horizontal scrolling.
- Make sure tables and cards adapt properly to the available width.

11. CONSISTENCY
Apply the same design language across all User Story 2 / Payroll-related pages:
- Create Payroll
- Payroll Batches/List
- Payroll Batch Detail
- Create Payroll modal
- Any other pages/components belonging to User Story 2

IMPORTANT SCOPE RESTRICTION:
Do NOT modify global styles unless they are already specifically shared by User Story 2.

Do NOT make changes that affect other user stories or unrelated pages.

If a shared component is used by multiple pages, do not globally change its appearance just for User Story 2. Instead, use a User Story 2-specific class, wrapper, variant, or scoped styling where appropriate.

Reuse existing shared components and existing design variables whenever possible.

Do not unnecessarily create duplicate components.

Before modifying anything, inspect the existing project structure and identify:
- shared layout
- sidebar
- header
- global styles
- design variables
- shared buttons
- shared tables
- shared modal/input components

Only make the minimum necessary changes to achieve a polished UI.
